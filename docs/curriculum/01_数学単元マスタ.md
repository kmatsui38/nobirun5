## 単元一覧（教科×学年×領域）

領域: **A** 数と式 / **B** 図形 / **C** 関数 / **D** データの活用

| 学年 | A 数と式 | B 図形 | C 関数 | D データの活用 |
|---|---|---|---|---|
| 中1 | 正の数と負の数 / 文字を用いた式 / 一元一次方程式 | 平面図形 / 空間図形 | 比例、反比例 | データの分布 / 不確定な事象の起こりやすさ |
| 中2 | 文字を用いた式 / 連立二元一次方程式 | 基本的な平面図形の性質 / 図形の合同 | 一次関数 | データの分布 / 不確定な事象の起こりやすさ（確率） |
| 中3 | 正の数の平方根 / 簡単な多項式 / 二次方程式 | 図形の相似 / 円周角と中心角の関係 / 三平方の定理 | 関数 y=ax² | 標本調査 |

全 **19単元**。各単元は指導要領の「内容」に対応し、YAMLに以下を収録している:

- `knowledge_skills` — ア「知識及び技能」の事項（原文）
- `thinking_skills` — イ「思考力、判断力、表現力等」の事項(原文)
- `terms` — 学年×領域の〔用語・記号〕
- `handling` — 関連する〔内容の取扱い〕

## nobirun5 での使い方（想定）

1. **出題スコープの定義**: AI問題生成は必ずいずれかの単元ID（例: `M2-C1`）に紐づけ、`knowledge_skills` / `thinking_skills` のどの事項を測る問題かを指定する。
2. **苦手マップの軸**: 苦手マップのマス＝この単元マスタの単元。定着度は単元×事項レベルで記録する。
3. **さかのぼり出題の基盤**: 単元間の前提関係(例: 一次関数 ← 比例・反比例 ← 文字を用いた式)は次ステップで `prerequisites` としてこのマスタに追加する。

## 出典に関する注意

- ユーザー提供のPDF3点のうち、**ファイル名とファイル内容が入れ替わっている**ものがある:
  - 「…数学.pdf」→ 中身は **解説 総則編**
  - 「…総則.pdf」→ 中身は **解説 数学編**(本マスタの出典)
  - 「…「生きる力」.pdf」→ **平成20年告示の旧課程** の指導要領本体(現行課程ではないため本マスタでは不使用)
- 本マスタは現行課程である**平成29年告示**版に基づく。
- PDFからの機械抽出のため、原文の表記(上付き文字・記号)の一部を整形している。内容の正確性はスポットチェック済みだが、問題生成に使う前に単元単位での再確認を推奨。
